GitHub Pages Deployment Guide

1. Create or open the GitHub repository for this project.
2. Upload these five files to the repository root:
   - index.html
   - characters.js
   - README.md
   - DATA_SOURCES.md
   - DEPLOY-V1.0.txt
   - TEST-REPORT-V1.0.md
3. Open GitHub repository Settings.
4. Select Pages.
5. Under Build and deployment, select:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
6. Save the settings.
7. Open the published GitHub Pages address after deployment completes.

Update procedure:
- Replace index.html when changing interface or game logic.
- Replace characters.js when adding or revising character data.
- Keep all files in the same folder.

Recommended testing after upload:
- Windows: Chrome and Edge
- macOS: Safari and Chrome
- iPhone/iPad: Safari
- Android: Chrome
- LINE in-app browser; if incomplete, use Safari or Chrome

Privacy:
No login, upload, visitor counter, analytics, or external tracking is included.
