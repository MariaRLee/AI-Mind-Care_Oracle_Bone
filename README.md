## V1.2 improvements
- Active gameplay shows only the target character and selectable script symbols.
- Pinyin, Chinese meaning, and English meaning are hidden during the five-step challenge.
- After completing all five stages, a fireworks result pop-up displays completion time, correct percentage, score, and an encouragement message.
- Correct percentage equals correct selections divided by all selections for that character.
- Full evolution and bilingual meaning appear only after the five stages.
- Preserves 中文 / English, Home, IP notice, local-only privacy, and responsive layouts.
