# AI-Mind Care 甲骨文尋字｜Oracle Bone Character Quest V1.1

## Subtitle
穿越三千年的文字密碼  
Unlocking the Script of 3,000 Years

## V1.1 improvements
- Removed the 中英 button and kept only 中文 / English.
- Added an Intellectual Property Rights Notice to 使用指南 / User Guide.
- Upgraded gameplay: for each modern character, users identify five stages in sequence:
  甲骨文 → 金文 → 小篆 → 隸書 → 楷書.
- After all five stages are completed, the game shows the full evolution, completion time, score, and encouragement.
- Preserved Home button, bilingual interface, local-only privacy design, and responsive layouts.
