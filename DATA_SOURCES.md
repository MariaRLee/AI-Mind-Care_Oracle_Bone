# Data Sources and Design Notes — V1.3

## Character database
V1.3 contains 30 beginner-friendly characters:

日、月、山、水、火、木、人、口、目、田、雨、川、土、石、門、手、足、耳、心、女、子、馬、牛、羊、犬、鳥、魚、龜、禾、竹。

Each record contains:
- an oracle-bone educational SVG reconstruction
- a bronze-script educational SVG reconstruction
- a small-seal educational SVG reconstruction
- clerical and regular-script display
- pinyin, Chinese meaning, English meaning, and a short bilingual note

## Important historical note
Ancient Chinese character forms can vary across objects, periods, inscriptions, rubbings, transcriptions, and scholarly interpretations. The SVG symbols in this activity are simplified, beginner-friendly educational reconstructions designed for consistent display across devices. They are not scans, rubbings, facsimiles, formal palaeographic transcriptions, or references for authentication.

## Display policy
The early-script forms are embedded as local SVG paths so they can display consistently on Windows, macOS, iPhone, iPad, and Android without relying on uncommon external fonts.

## Privacy and external resources
The game does not require login, upload answers, use visitor counters, or connect to external analytics or tracking tools.


## Pinyin and Zhuyin
Pinyin and Zhuyin use the common modern Mandarin reading associated with the meaning shown in this educational set. Where a character has multiple readings, this version presents the reading used for the displayed meaning; for example, 龜 meaning “turtle” is shown as guī / ㄍㄨㄟ.
